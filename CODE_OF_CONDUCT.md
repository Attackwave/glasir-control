# Code of Conduct

## Our commitment

We are committed to a professional, respectful, and constructive community.
Participation must be free from harassment, discrimination, intimidation, and
personal attacks.

## Expected behavior

- Focus feedback on code, evidence, and outcomes.
- Assume good intent and ask for clarification before escalating disagreement.
- Respect different experience levels, backgrounds, and communication styles.
- Report security concerns privately through the process in `SECURITY.md`.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, sexualized content, or
deliberate disruption of project work are not acceptable.

## Enforcement

Project maintainers may remove content, reject contributions, or restrict
participation when this code is violated. Reports should be sent privately via
the repository security-advisory channel.
